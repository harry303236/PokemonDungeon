| ADR-008 | learnset 固定用 scarlet-violet | 資料最新且完整；用最大 version id 會挑到不完整的群組 |
| ADR-009 | 屬性免疫（0×）改為 0.25× | 避免單屬性流派遇到特定怪就完全打不動 |
| ADR-010 | 預設 placeholder 美術、全部走 SpriteProvider；不 commit 官方素材 | IP 風險 |
| ADR-011 | 存檔用 localStorage + .bak + version migration | 零後端 |
| ADR-012 | UI 用 DOM overlay，HUD 用 Phaser 畫 | 排版好做＋效能 |
| ADR-013 | 地城中途不存檔 | 簡化；一層只有 3–5 分鐘 |
| ADR-014 | 不是 roguelike：裝備與成長永久保留 | 核心是刷寶 |

## B. 舊 repo（pokemonpoe）可轉用的「概念」（不准複製程式碼／素材）
- 特性用「hook」表示（傷害前／命中後／每秒）的資料驅動做法 → 本作 `AbilityData.hooks`。
- 天氣是罕見的全域事件，用屬性倍率表＋輕微疊色表現；co-op 時由 host 決定並廣播 → 本作 `04` §7。
- 命中事件（hit event）串起各種被動 → 本作 EventBus `hit:pre/post`。
- Co-op：WebRTC reliable ordered DataChannel、host 權威、約 15 Hz 狀態同步、簡單的 signaling；之後可以做 payload 壓縮。
