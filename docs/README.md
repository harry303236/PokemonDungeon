# PokeDungeon 文件集（給 AI coding agent）

本資料夾是新 repo `pokedungeon` 的**唯一規格來源**。專案從零開始；不得複製任何舊 repo（`pokemonpoe`／PokeSurvivor fork，PolyForm Noncommercial 授權）的程式碼或素材。

## 閱讀順序
1. `AGENTS.md`：開發規則（必讀，先讀）
2. `01-GDD 遊戲設計.md`：要做什麼
3. `02-技術選型與架構.md`：怎麼組織程式
4. `03-資料規格.md`：所有型別與 JSON schema、資料管線
5. `04-戰鬥與技能系統.md`：公式、事件掛點、詞綴
6. `05-美術與特效規格.md`：素材抽象層、VFX、UI 畫面
7. `06-開發里程碑.md`：**依序實作 M0→M5**，每個里程碑都要通過驗收標準
8. `07-開放問題與決策紀錄.md`：遇到不確定先查這裡；沒寫到就用「預設值」並追加一條 ADR
9. `08-御三家技能樹設計.md`：御三家流派、節點、詞綴的內容來源（MVP 只實作小火龍線）

## 使用規則
- 規格衝突時優先順序：`AGENTS.md` > `07`（決策紀錄）> `04` > `03` > `01` > `08`。
- `08` 標【API】的是事實資料，標【設計】的是可調整的設計值；數值若與 `04` 衝突，以 `04` 為準。
- 不准停下來問問題：依 `07` 的預設值繼續做，並在 `docs/decisions.md`（新 repo 內）記錄新決策。
