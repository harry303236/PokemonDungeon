# 06 開發里程碑（MVP）

MVP 範圍：只有小火龍線（Lv1–50、兩次進化）、1 座地城 `ember-cavern` 5 層（T1–T3）、10 種怪＋大岩蛇 Boss、掉寶＋詞綴、技能樹、存檔。
每個里程碑都要做到：lint／typecheck／test／build 全綠，在 `docs/progress.md` 打勾，並 tag `m0`…`m5`。

## M0 專案骨架與資料管線
- [ ] Vite + TS strict + Phaser 3 + Vitest + ESLint/Prettier + zod 初始化；照 `02` §2 建立資料夾
- [ ] `AGENTS.md`、`docs/`（複製本文件集）、`CREDITS.md`
- [ ] `scripts/fetch-pokeapi.ts`（快取、重試、zh-hant 名稱、learnset 用 scarlet-violet）
- [ ] `data/design/species-list.json`：charmander、charmeleon、charizard、squirtle 線、bulbasaur 線、rattata、zubat、geodude、diglett、slugma、paras、oddish、magnemite、poliwag、gastly、onix
- [ ] `scripts/build-data.ts` + `validate-data.ts` + zod schemas（`03` 全部型別）
- [ ] `core/rng.ts`（mulberry32）、`core/events/event-bus.ts`
- [ ] Boot → Title 畫面能顯示「小火龍」（從 generated JSON 讀出的 zh-Hant 名字）
**驗收**：`npm run data:fetch && npm run data:build` 在乾淨的 clone 能完整跑完；`species.json` 的小火龍種族值 = 39/52/43/60/50/65；charmeleon 的 evolvesTo.minLevel = 36；runtime 的 network 面板沒有任何對 pokeapi.co 的請求。

## M1 移動、戰鬥核心、一間房間
- [ ] 自製 ECS（`02` §4）、固定步長 sim、空間雜湊碰撞
- [ ] InputMap（WASD＋滑鼠瞄準＋閃避）→ InputCommand
- [ ] PlaceholderProvider、entity-view
- [ ] stat-calc（`04` §1）、damage.ts（`04` §2）、type-chart
- [ ] move-executor＋shape：projectile、arc-melee、cone、beam、zone、aoe-target、dash、aoe-self、buff-self
- [ ] 冷卻／能量（`04` §5.2）；普攻＝ember
- [ ] 狀態：burn、paralysis、fear、blind、bound、flinch、confusion
- [ ] 測試房間：玩家小火龍 Lv10 vs 5 隻 rattata（melee-rusher AI）
- [ ] 傷害數字、HUD（HP／能量／4 槽冷卻）
**驗收**：單元測試——Lv10 小火龍用火花打 Lv10 小拉達時，傷害落在測試快照範圍內；冷卻 flamethrower = 2.667 s ±0.01；burn DoT 每秒 2%。手動測試——能移動、閃避、施放 4 招，打死怪物；300 個投射物時仍有 60 fps。

## M2 地城生成與怪物
- [ ] BSP 樓層生成（`01` §5）、tilemap-view（Kenney tile，或後備色塊）、牆壁 bitmask
- [ ] 10 種 AI 原型＋`monsters.json`；spawner（pack、菁英詞綴）
- [ ] 樓層流程：出口在清完 Boss 房／一半以上房間後開啟 → FloorTransition → 下一層；營火換招
- [ ] 天氣系統（樓層天氣、sunny-day、祭壇）＋疊色
- [ ] 大岩蛇 Boss 3 階段＋預警圈
- [ ] 小地圖
**驗收**：同一個 seed 會生成相同的樓層（快照測試）；1–5 層可以通關並擊敗 Boss；每種怪的行為肉眼可分辨；sun 時火招傷害 ×1.5（測試）。

## M3 成長：等級、進化、技能樹
- [ ] XP／升級（`01` §4）、進化 Lv16／36（演出＋可延後）
- [ ] `skill-trees/charmander-line.json`：照 `08` §1.3 寫完 3 分支 × 4 層所有節點（招式節點＋被動＋keystone）
- [ ] skill-tree.ts 規則（前置、tier 解鎖、分支點數門檻、重置）
- [ ] 技能樹 UI、招式配置 UI
- [ ] 特性：blaze、solar-power（技能樹 C 或 A 分支的 keystone 解鎖隱藏特性 solar-power，見 ADR-006）
**驗收**：測試——Lv15 不能點 tier2；進化後能點；move 節點全部 ∈ learnset（build-data 驗證）；手動測試——從 Lv1 玩到 Lv36 能看見兩次進化，模型跟數值都會變。

## M4 掉落、物品、詞綴
- [ ] items.json（6 個攜帶道具＋小火龍可學招式的 TM）、affixes.json（`04` §6.5 共 18 個）
- [ ] loot-roller（稀有度權重、Tier 加成、requires 篩選、rolls）、地面掉落物顯示與撿取
- [ ] 背包、紙娃娃、Tooltip、裝備規則（1 shape／TM、全身 1 個 cost）
- [ ] 詞綴執行：stat／shape／trigger／reaction／cost 五類；ChainContext 遞迴保護
- [ ] 反應：wet（敵人 poliwag 的水招也會讓玩家 wet）、burn 層、fire-field
**驗收**：測試——固定 seed 擲 10,000 次，稀有度分布在 `01` §7.2 ±2% 之內；ember-chain 一排 10 隻怪最多連鎖 3 段；split-flame 生成 3 道 beam；不合法的裝備組合會被拒絕。手動測試——build 範例「永晝砲台」「殘火龍騎」「焚翼遊俠」（`08` §1.6）都能組出來，玩起來手感明顯不同。

- [ ] 設定（音量、特效強度、震動、鍵位）、i18n 完整（zh-Hant 預設，en 可以先放 key）

- [ ] 部署：`npm run build` 的靜態檔可以放到 GitHub Pages
**驗收**：重新整理頁面後，等級／技能樹／背包／裝備都完整保留；手動把存檔改壞後能從 .bak 還原；完整玩一輪（新遊戲 → T1 通關 → 進化 → 拿到詞綴 → T3 Boss）沒有阻斷性 bug。
