# 05 美術與特效規格

## 1. IP 風險聲明（必讀）
寶可夢的名稱、角色設計與美術都是 Nintendo／Game Freak／The Pokémon Company 的智慧財產。本專案目前是**個人非商業原型**。
- repo 內**不得**放官方美術、sprite 圖片、音樂。
- 所有角色圖都走 `SpriteProvider` 抽象層；預設用 `placeholder`（程式繪製）。之後可以替換成原創美術（例如把「火蜥蜴」重新設計成原創生物），這樣就能去除 IP 風險。
- 資料層（名稱、招式名）也要能換：所有玩家可見名稱都走 i18n，`LocalizedName` 可以由 `data/design/rename-overrides.json` 覆寫。

## 2. Tileset（CC0）
- 使用 Kenney 素材（CC0）：`Roguelike Caves & Dungeons`、`Tiny Dungeon`（擇一當主 tileset，tile 16 px → 遊戲中放大 2 倍成 32 px），UI 用 `UI Pack`、圖示用 `Game Icons`。音效用 `Kenney Impact Sounds`／`Interface Sounds`。
- 下載後放在 `public/assets/tilesets/kenney-<pack>/`，並在 `CREDITS.md` 列出包名、網址、授權。Agent 無法下載時：用程式生成色塊 tile（地板 #3a2f2a、牆 #1c1512、熔岩 #c2410c）頂替，API 保持不變。
- 地城自動拼接：牆面用 4-bit bitmask 選 tile（`tile-rules.json` 定義 mask→tile index）。
- 圖層：`floor`、`decor`、`walls`（碰撞）、`overlay`（天氣色調）。

## 3. Sprite 抽象層
```ts
interface SpriteProvider {
  preload(scene: Phaser.Scene, keys: string[]): void;
  create(scene: Phaser.Scene, key: string, opts: { tint?: number; scale?: number }): EntityVisual;
}
interface EntityVisual { root: Phaser.GameObjects.Container; play(anim: 'idle'|'walk'|'cast'|'hit'|'die', dir?: Dir8): void; setFacing(rad: number): void; flash(color: number, ms: number): void; destroy(): void; }
```
- `PlaceholderProvider`（MVP 預設）：寶可夢畫成圓形身體＋朝向三角形。顏色＝第一屬性色（見 §4），外框＝第二屬性色；體型依 `radius`；頭上顯示 dexNo 小字。怪物外框紅色、菁英金色外框加光環、Boss 3 倍大並帶 HP 條。動畫用 tween 表現（walk 上下彈跳、cast 放大 1.1、hit 閃白、die 縮小淡出）。
- `SpritesheetProvider`（之後用）：讀 `public/assets/sprites/manifest.json`：`{ key, sheet, frameW, frameH, anims: { walk: { dir8: true, frames: [...] , fps } } }`。
- 選哪個 provider 由 `settings.spriteProvider` 決定，預設 `placeholder`。

## 4. 屬性色與 VFX
| 屬性 | 主色 | 粒子特徵 |
|---|---|---|
| fire | #ff6a1a | 往上飄、橘→紅漸層、尾端有煙 |
| water | #3b8bff | 往下落的水滴、濺射圈 |
| grass | #4cc35a | 葉片旋轉、緩慢飄落 |
| dragon | #7a5cff | 紫色鱗光、拖尾 |
| flying | #a8c8ff | 白色風線 |
| normal | #d9d4c7 | 白色衝擊星 |
| poison | #a64dd6 | 氣泡 |
| electric | #ffd51a | 鋸齒閃光 |
| rock/ground | #b08a52 | 碎石 |
| ghost | #5b4a8a | 半透明煙 |
| 其他 | 依 PokeAPI 的慣用色 | 通用光點 |
- VFX preset（`vfx-presets.json`）：`{ id, emitter: Phaser ParticleEmitter config, colorFrom:'type', blend:'ADD'|'NORMAL', shake?: number, flash?: boolean }`。
- 每種 shape 對應的預設 VFX：projectile＝發光核心＋拖尾；beam＝矩形加上 ADD 粒子；cone＝扇形粒子噴射；zone＝地面圓形（alpha 0.35）＋粒子；aoe-target＝預警圈（0.4 s）→ 爆炸；dash＝殘影；buff＝自身光環。
- 粒子貼圖：用程式生成 4 種（圓點 8 px、軟光暈 32 px、葉片、火焰形），在 Boot 時 `generateTexture`，不需要外部檔案。
- 天氣疊色：sun（#ffcb3d，alpha 0.07＋光斑）、rain（#3256aa，alpha 0.10＋斜線雨）、sand（#e0bf73，alpha 0.10＋流沙粒子）、snow（#dfefff＋雪點）。
- 狀態圖示：頭頂小 icon（burn 火焰、poison 紫泡…）；tag 用身體外圍的小點（wet 藍點、seeded 綠點）。
- 傷害數字：白色一般、黃色效果絕佳、灰色效果不好、橘色大字暴擊、綠色回復、紫色 DoT。
- 設定裡要有「特效強度」（低／中／高），粒子數 ×0.3/0.6/1，另有「螢幕震動」開關。

## 5. UI 畫面清單
| 畫面 | 內容 |
|---|---|
| Title | 新遊戲／繼續／設定／製作群 |
| StarterSelect | 3 張卡（MVP 只能選小火龍），顯示屬性、種族值雷達圖、流派簡介 |
| Hub | 城鎮地圖（簡單的一個房間）：NPC 鍵（技能重置、商店 M5）、地城入口、倉庫箱 |
| DungeonSelect | 地城卡、Tier 選擇（顯示推薦等級）、樓層天氣機率 |
| HUD | 左下 HP／能量條＋等級／XP；下方中間 普攻＋4 招槽（冷卻轉圈、能量不足時變紅、按鍵提示）；右上 小地圖、樓層／Tier、天氣 icon＋剩餘時間；左上 身上狀態與 buff 層數；Boss HP 條在上方中間 |
| Inventory（I） | 左：寶可夢紙娃娃（4 招＋各招 TM＋1 攜帶道具＋特性）；右：背包格（10×6）；滑過顯示 Tooltip |
| Tooltip | 名稱（依稀有度上色）、類別、基礎數值（威力／PP→冷卻／能量）、詞綴列表（質變詞綴有特殊 icon，cost 紅字）、與目前裝備比較 |
| SkillTree（K） | 3 欄分支 × 4 層，節點圖示（招式用屬性色、被動方形、keystone 六角形）、連線、未解鎖的層顯示鎖頭＋「Lv16 進化至火恐龍」；剩餘點數；右鍵退點（在城鎮免費退點到 0，只限本次 session 新增的點） |
| MoveLoadout | 已解鎖招式列表 → 拖曳到 4 槽 |
| Evolution | 進化演出（白光、剪影變形 1.5 s）＋新解鎖節點列表 |
| Pause / Settings | 音量、特效強度、震動、鍵位、語言、sprite provider |
| GameOver / Victory | 統計、掉落清單 |
- UI 技術：用 DOM overlay（HTML/CSS，放在 `src/ui/`），疊在 Phaser canvas 上，比較好排版跟測試；HUD 例外，用 Phaser 畫（效能考量）。字型用 `Noto Sans TC`（透過 @fontsource 打包，不依賴 CDN）。
